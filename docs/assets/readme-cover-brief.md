# README cover design brief

Created for the KINETICKK README on 2026-10-30. No reference images or
third-party artwork were supplied. This is promotional artwork, not a
screenshot of the game.
The cover is stored as `readme-cover.png`.

## Design brief

Use case: logo-brand. Asset type: a wide 3:1 horizontal editorial title artwork for the GitHub README of KINETICKK, a minimalist physics action roguelite with an orbiting Core and dangerous singularity. Create a finished, exceptionally sophisticated typographic poster; not a screenshot, not a UI mockup. Canvas approx 1800x600. Background almost-black warm green #0A0B0A, dominant bone-white #F1F0E8 and electric acid-lime #D8FF3E, tiny hot-pink #FF3B6B danger accent. LEFT 65%: huge bold tightly tracked extended geometric grotesk wordmark, precise text 'KINETICKK' spelled K I N E T I C K K, in bone white; below it much smaller but still legible widely tracked uppercase 'MOMENTUM IS EVERYTHING'. RIGHT 35%: an elegant, graphic orbital composition: a small solid bone-white core with a sweeping tapering acid-lime curved motion trail looping dynamically around a small hot-pink outlined singularity; fine ellipses and a couple of geometric fragments; carefully balance it to suggest speed and control. Visual style: high-end Swiss typography meets 1990s experimental techno sleeve, flat crisp vector-like shapes with subtle printed halftone dots on the right, measured negative space, deliberately restrained detail, a little asymmetry, horizontal hairline rules. No gradients on text, no 3D metallic letters, no space photography, no rainbow, no robot, no starfield, no extra invented objects, no fake HUD or metrics, no device mockups, no badges, no version numbers, no logos from other companies, no watermark. Only these two text lines. Keep generous 70px clear margin and make the title readable when scaled to a GitHub README width of 850px. Entire artwork fills the canvas; no outside frame or presentation background.
